## 🛠️ البنية التقنية (Tech Stack)
* **Frontend:** Next.js 15 (App Router) + Tailwind CSS + Lucide Icons + shadcn/ui.
* **Backend & Database:** [PocketBase](http://pocketbase-qfp2khqiopiac7purq5j4byg.185.183.181.158.sslip.io) (Go/SQLite self-hosted on VPS).
* **Storage:** Cloudflare R2 (S3-compatible, zero egress).
* **Design Aesthetic:** Dark Luxury Automotive (`#0A0D14` background, `#00A2E8` Electric Cyan, `#E50914` Crimson Red).
